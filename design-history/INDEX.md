# Archived design and documentation history

Everything in this directory is superseded evidence. It is retained temporarily for traceability and can be removed without changing the application, generated contracts, active skills, tests, or current documentation.

Current implementation authority starts at [../START_HERE.md](../START_HERE.md). Active prototype documents are listed in [../prototype/README.md](../prototype/README.md). Current files must not link here for behavior or engineering requirements.

## Archive groups

- `framework-v1.2/`: the former root UX framework, reference images, fixtures, comment examples, and renderer. It predates the current report-focused workspace contract. The similarly named `../qa-skills/framework/` remains active and is not part of this archive.
- `superseded-prototype-docs/`: replaced prototype plans, reviews, UX specifications, adoption notes, and implementation screenshots through the pre-F3 releases.
- `prototype-plan-v0.1/`, `prototype-contract-v0.2/`, and `prototype-api-v0.3/`: earlier contract snapshots.
- `handoff-v1.4/`: an earlier coding-agent handoff.
- `browser-tests-v1.10/`: historical browser test sources.
- numbered PNG files: exploratory and superseded interface studies.

The source packaging script excludes this directory, so archived material is no longer included in the current release manifest or bundle.
